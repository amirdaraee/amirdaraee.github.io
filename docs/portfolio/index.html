NameWise

An AI-powered CLI tool that automatically renames files based on their content. It leverages cloud models like Claude and OpenAI, or local LLMs such as Ollama and LMStudio, to generate clean, descriptive filenames.

Designed with privacy and flexibility in mind, NameWise supports multiple file types, customizable templates, and dry-run previews — making file organization smarter, faster, and more intuitive.

Technology used

Node.js TypeScript OpenAI Claude Ollama LMStudio
